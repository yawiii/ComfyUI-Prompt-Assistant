## 3. Чек-лист ручной приёмки (выполнить в живом ComfyUI)

Подготовка: установить форк (см. `README_RU.md` §4), убедиться, что оригинал отключён,
Ollama запущена с `gemma4:e4b`, интерфейс переключён на «Русский».

1. **TR-01/02/04 (нода):** в workflow добавить ✨Prompt Translate; проверить Combo
   «Английский/Русский/Китайский»; EN→RU: «a girl in a red dress, (masterpiece:1.2), LoRA: xyz» →
   ожидаем русский текст с сохранением `(masterpiece:1.2)` и `LoRA: xyz`. RU→EN аналогично.
   Длинный текст ~3000 знаков (TR-03) — без обрезки абзацев.
2. **TR-01/02 (кнопка):** в текстовом поле виджета набрать английский текст → «Перевод» → русский;
   русский текст → «Перевод» → английский. Проверить настройку «Целевой язык кнопки перевода»
   (Авто/ru/en/zh) в Настройках.
3. **UI-01:** открыть панель помощника → открыть «Настройки» ComfyUI → вкладка ✨Prompt Assistant:
   настройки должны сразу принимать ввод; открыть «API-менеджер» из вкладки — он должен быть
   ПОВЕРХ окна настроек; закрыть; снова открыть «Настройки» — окна PA не должны его перекрывать.
4. **UI-02:** открыть/закрыть API-менеджер и Менеджер правил по 10 раз (крестик, Esc, отмена):
   проверить, что нет зависших затемнений, дублирующихся кнопок, что ввод работает сразу.
5. **UI-03:** изменить настройку → «Отмена» → переоткрыть (изменения не применились);
   изменить → «Сохранить» → перезапуск ComfyUI → настройка сохранилась.
6. **UI-04:** пройтись по всем экранам (панель, меню, настройки, API, правила, теги, история,
   caption, видео-кадры, справка узлов) — не должно быть китайских иероглифов (кроме
   самоназваний языков в селекторе языка и содержимого пользовательских правил).
7. **UI-05:** масштаб 100% и 125% в Chromium и Firefox: окна, скроллы, Combo, Tab/Esc.
8. **REG-01:** открыть прежние workflow с ✨Prompt Translate (`target_language: English/Chinese`)
   — параметры на месте, перевод работает; Ollama `gemma4:e4b` отвечает; после генерации модель
   выгружается (если включено).
9. **REG-02:** лог ComfyUI при старте — без ошибок импорта плагина; сообщения мигратора о
   «增量更新 (v2.1 -> v2.2)» для system_prompts — ожидаемое поведение.
