## 2. Китайские строки: аудит и итог

- Метод: скрипт-аудит извлекает строки в UI-контекстах (`label/title/tooltip/name/text/placeholder/
  summary/detail`, `tUI(...)`, `showStatusTip`, `textContent`, `innerHTML`) из всех 25 JS-файлов.
- Было (до форка): 303 уникальные UI-строки, 33 отсутствовали в `locales/ru/ui.json`,
  2 были в en, но не в ru.
- Стало (после этапа D): 31 ключ добавлен в `ru/ui.json`; непокрытыми остаются только
  самоназвания языков в селекторе языка интерфейса (简体中文/繁體中文/日本語) — это
  осознанное UX-решение (языки подписываются на языке самого языка), они не являются
  «иероглифами по ошибке».
- Фолбэк: `uiI18n.js` — незнакомый ключ при русской локали теперь показывает английский
  текст (раньше — китайский).
- Динамические строки (конкатенации) не могли локализоваться DOM-методом — переведены
  на `tUI()`-композицию: «Переключено на: …», «Ошибка переключения: …», кэш перевода.
- Логи серверной консоли (中文) не являются UI и не локализуются — вне рамок ТЗ.
