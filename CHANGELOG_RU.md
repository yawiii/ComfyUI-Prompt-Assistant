# CHANGELOG (RU-fork)

Все заметные изменения форка impxiii/ComfyUI-Prompt-Assistant относительно upstream
yawiii/ComfyUI-Prompt-Assistant. Формат по мотивам Keep a Changelog; версии — кодовые
этапы, а не релизы плагина.

## [2.0.6-ru.1] — 2026-11-09

База: upstream `e0587e6` (v2.0.6). Ветка: `feature/russian-localization-ux`.

### Added (добавлено)
- **Перевод EN→RU / RU→EN / ZH→RU**:
  - нода `✨Prompt Translate`: целевой язык `Russian` (Combo: Английский/Русский/Китайский,
    локализованные подписи через `locales/*/nodeDefs.json`);
  - новый модуль `utils/language.py`: определение en/ru/zh (кириллица, смешанный текст с
    LoRA-терминами → `auto`);
  - фронтенд: кнопка «Перевод» у текстовых полей распознаёт кириллицу; при русской локали
    автоматически переводит en→ru / zh→ru / ru→en;
  - настройка «Целевой язык кнопки перевода» (`PromptAssistant.Features.TranslateTargetLang`:
    Авто/ru/en/zh);
  - строгие правила перевода `EN → RU (strict)` и `RU → EN (strict)` в шаблоне
    (`system_prompts_template.json`, версия 2.1 → 2.2; доставляются мигратором, пользовательские
    правила не затрагиваются);
  - выбор правила перевода по направлению в `services/llm.py` (приоритет: явная активация
    пользователя → правило направления → прежнее поведение) + встроенная строгая инструкция-фолбэк.
- **Локализация**:
  - 31 недостающий ключ в `locales/ru/ui.json` (позиции панелей, меню справки узлов, действия
    копирования caption, статус-сообщения тегов/видео, переключение сервисов);
  - английский фолбэк для незнакомых ключей вместо китайского (`uiI18n.js`);
  - перевод справки узлов на русский (`nodeHelpTranslator.js`: цель «Перевести на русский»,
    авто-выбор при русской локали);
  - динамические статус-подсказки («Переключено на: …», «Ошибка переключения: …», кэш перевода)
    локализуются через `tUI()`.
- **Тесты** (`tests/`, 22 шт., чистый stdlib): `python -m unittest discover -s tests -v`.
- Документация: `README_RU.md`, `docs/DIAGNOSIS_RU.md`, `docs/UI_AUDIT_RU.md`,
  `docs/TEST_REPORT_RU.md`, `CHANGELOG_RU.md`.

### Fixed (исправлено)
- **Окна/модальные слои (P0)**:
  - `popupManager.showPopup`: `ReferenceError` (неопределённые `oldPopup`/`oldPopupInfo`) —
    ломал переключение popup'ов, оставлял «осиротевшие» окна и навсегда зависший
    флаг `_isTransitioning`;
  - «прозрачная ловушка»: закрывающиеся модалка/подложка (300 мс анимации) больше не
    перехватывают клики (`pointer-events: none` для `.modal-hide`/`.overlay-hide`);
  - единая политика слоёв: модалки PA в реестре (стек), при открытии диалога ComfyUI
    (например «Настройки») окна PA опускаются под него и не перехватывают ввод, после
    закрытия диалога — восстанавливаются; модалки, открытые из вкладки PA в настройках,
    по-прежнему открываются поверх;
  - Esc закрывает верхнюю модалку PA (и не перехватывается окном, ушедшим под диалог ComfyUI);
    фокус переносится в модалку и возвращается при закрытии;
  - защита от двойного открытия модалок (быстрый двойной клик).

### Changed (изменено)
- `node/translate_node.py`: неизвестное значение `target_language` теперь вызывает понятную
  ошибку вместо молчаливого перевода на китайский; логи направлений включают `ru`.

### Compatibility (совместимость)
- Значения Combo `English`/`Chinese` в сохранённых workflow не изменялись; `Russian` — новая
  опция. Старые workflow открываются и работают (покрыто тестом).
- `requirements.txt` и `pyproject.toml` не менялись. Новых зависимостей нет.
- Имена нод, входов/выходов и сериализация не менялись.
- Осторожно: если вы редактировали **встроенное** правило `ZH` вручную, бамп версии шаблона
  синхронизирует его с шаблоном (поведение upstream для встроенных правил). Перед обновлением
  сохраните правку как отдельное пользовательское правило.

### Risks / ограничения
- GUI-проверка не выполнялась: UI-фиксы подтверждены статическим анализом кода; обязательный
  ручной чек-лист — в `docs/TEST_REPORT_RU.md` §3.
- Кнопки image-caption по-прежнему выдают китайский/английский текст (русская цель caption
  не добавлялась — требуется отдельная vision-правила).
- Логи серверной консоли остаются на китайском.

### Замечания по установке (из живой диагностики)
- В `custom_nodes` не должно быть двух копий плагина: старая копия перезаписывает
  регистрацию нод (симптом: `Russian` отсутствует в ноде при обновлённом JS).
- **После обновления плагина обязателен перезапуск ComfyUI** — определения нод читаются
  при старте, и жёсткое обновление страницы браузера (Ctrl+Shift+R) для нового JS.
